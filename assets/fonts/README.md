# Local typefaces

Barlow Condensed (600, 700, 800), DM Sans and JetBrains Mono are served locally, with their SIL Open Font License files alongside them.

These same font files are used by the Bivouac Club reference design. Source families: [Barlow](https://github.com/jpt/barlow), [DM Sans](https://github.com/googlefonts/dm-fonts), [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono).
