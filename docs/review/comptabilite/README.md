# Accounting workspace comparison

All new records and receipts shown here are synthetic test fixtures.

Before: **Activité** opened the monthly planned-booking summary and rates. It did not provide invoice, expense-claim or receipt-intake workflows. [Before](before-monthly.png).

After: **Comptabilité** provides a ledger, customer invoices, purchases/expense claims, a review queue and accountant export. Existing booking totals and rates remain directly accessible in the last tab. [Desktop](after-1440.png), [phone](after-390.png).

The local reader proposes two separate paper areas from one synthetic photo. Users can adjust the areas; recognized rows remain drafts until reviewed. [Two receipts](two-receipts.png).

See [accounting behavior and checks](../../comptabilite.md). Screenshots illustrate product behavior; final validation results belong in the PR evidence.
